MODIFICATIONS by VPS Agent, 2026-11-03:
* TerminalView and TerminalViewClient use the new neutral RemoteSession interface
  instead of the final JNI-coupled local TerminalSession.
* TerminalSessionClient callback types use RemoteSession.
* TerminalView is non-final so an app subclass can enforce multiline paste,
  stale IME, mouse-paste and autofill safety. Rendering/parser algorithms are unchanged.
* RemoteSession.java and the Android-library Gradle build are new integration code.
* Main resources from both upstream modules are combined in one Android library.
* The application's remote adapter rejects OSC52 clipboard read/write callbacks;
  selection copy and explicit paste are separate user actions.
